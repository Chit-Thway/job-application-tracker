# Fictional job-advertisement samples

These files help the automated tests check how Job Application Tracker reads job advertisements from different layouts.

Every role, company, person, address, and contact detail here is fictional. The samples were written for this project and were not copied from a real employer or job board.

When adding a sample:

1. Use clearly fictional information.
2. Keep the layout feature that the test needs, such as a labelled salary or stacked heading.
3. Add or update a focused test that explains the expected result.
